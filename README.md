# Voice Agent

This repository is a placeholder. The voice-assistant prototypes are in [Voice-prototypes-two-stacks-](https://github.com/AdityaKundra/Voice-prototypes-two-stacks-).

That repo has two stacks:

- `voice-agent` — browser, LiveKit, a Flask faster-whisper sidecar, Ollama, and Sarvam text-to-speech
- `voice-agent-api` — LiveKit Agents worker with AssemblyAI, an OpenAI-compatible model, and Sarvam text-to-speech

Start there. Each folder has its own README and run steps.
